# সাশ্রয় (Shasroy)

Mobile-first e-commerce storefront for stationery, gifts, household essentials, and affordable decor in Bangladesh.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint
- `npm run typecheck` — run TypeScript checks

## Current scope

Phase 1 contains the project foundation: Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui conventions, design tokens, and the responsive site shell.

Database integration and product data begin in Phase 2.
